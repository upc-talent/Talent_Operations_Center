Staff Password Hashes (offline)

This page turns each staff password into a one-way PBKDF2-SHA256 hash and builds the value of the STAFF_ACCOUNTS secret. Everything happens inside this browser tab: the page is blocked from using the network, and nothing is saved.

  1. Type a password for every account, or press Generate all for strong random ones.
  2. Give each person their own password privately (write them down before closing this page — they can't be recovered from the hash).
  3. Press Build STAFF_ACCOUNTS, copy the result, and paste it as the value of the STAFF_ACCOUNTS secret in Supabase (Edge Functions → Secrets). Then close this tab.
